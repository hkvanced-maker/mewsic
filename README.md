# Sovio ☭

پخش‌کنندهٔ صوتی اندروید (فقط صدا) با موتور پخش مثل AntennaPod و امکانات اپ تمپو/پیچ.

## امکانات

- **کیفیت صدا در سرعت بالا**: همان موتور AntennaPod (ExoPlayer / Media3 + الگوریتم Sonic که زیر و بمی صدا را حفظ می‌کند). `wav` و `mp3` و بقیهٔ فرمت‌های رایج (m4a، ogg، opus، flac، aac …) پشتیبانی می‌شود.
- **سرعت**: پیش‌فرض ۰٫۲۵× تا ۳×؛ دکمهٔ «افزایش محدوده تا ۵×» اسلایدر را تا ۵× (۵۰۰٪) باز می‌کند. دکمه‌های ‎−/+‎ (گام ۰٫۰۵)، تایپ سرعت دقیق (روی عدد بزن) و **سرعت‌های ثابت**: ‎+‎ سرعت فعلی را اضافه می‌کند، نگه داشتن روی یک دکمه آن را حذف می‌کند.
- **Pitch** جدا از سرعت (‎−۱۲ تا ‎+۱۲ نیم‌پرده).
- **ویوفرم قابل زوم**: با کشیدن انگشت روی آن هر جای فایل را پیدا می‌کنی، با زدن روی آن می‌پری، با دو انگشت یا دکمهٔ ذره‌بین زوم می‌کنی (۱۰ ثانیه ← ۳۰ ثانیه ← ۲ دقیقه ← ۱۰ دقیقه ← کل فایل). زیرش اسلایدر معمولی هم هست.
- **تکرار بازه A-B**، تایمر خواب (دقیقه‌ای یا پایان فایل)، رد شدن از سکوت‌ها، تکرار/تصادفی.
- **دکمه‌های عقب/جلو با عدد دلخواه**: هر عددی از ۱ تا ۷۲۰۰ ثانیه (پیش‌فرض ۲۰ عقب و ۳۰ جلو). یا نگه داشتن روی دکمه‌ها در پخش‌کننده، یا بخش «دکمه‌های عقب / جلو» در تنظیمات پخش (آیکون تنظیمات بالای پخش‌کننده).
- **کنترل در صفحهٔ قفل و پردهٔ اعلان**: پخش/توقف، قبلی/بعدی و دکمه‌های عقب/جلو (با همان ثانیه‌هایی که تنظیم کرده‌ای). پخش با خاموش شدن صفحه ادامه پیدا می‌کند.
- **آخرین فایل پخش‌شده** هنگام ورود به برنامه (حتی بعد از بستن کامل برنامه) آمادهٔ ادامه است (از همان ثانیه‌ای که مانده بود). اگر می‌خواهی خود پخش‌کننده هم باز شود: منوی ⋮ ▸ «باز شدن پخش‌کننده هنگام ورود».
- **تقویت صدا (Volume boost)** تا ‎+۲۴ dB برای هر فایل جدا (ذخیره می‌شود) با **لیمیتر نرم‌افزاری look-ahead**: قله‌های صدا هرگز کلیپ نمی‌شوند، پس فایل‌های ضعیف بدون اعوجاج بلندتر می‌شوند. دکمهٔ «خودکار» از روی ویوفرم تقویت مناسب را پیشنهاد می‌دهد.
- **همهٔ فایل‌های صوتی گوشی** (MediaStore) با جستجو و مرتب‌سازی، باز کردن فایل از هر جا (دکمهٔ ‎+‎ بالا) و ظاهر شدن در منوی «باز کردن با» برای هر فایل صوتی.
- رابط انگلیسی و فارسی (راست‌به‌چپ).

## ساخت APK

### روش ۱: Android Studio
`File ▸ Open` و پوشهٔ پروژه را انتخاب کن، صبر کن Gradle sync شود، بعد `Build ▸ Build APK(s)`.
فایل: `app/build/outputs/apk/debug/app-debug.apk`

### روش ۲: خط فرمان (JDK 17 و Android SDK لازم است)
```
./gradlew assembleDebug
```

### روش ۳: GitHub Actions (بدون نصب چیزی)
پروژه را در یک مخزن GitHub آپلود کن؛ تب **Actions ▸ Build APK ▸ Run workflow**. بعد از چند دقیقه فایل `Sovio-APK` در بخش Artifacts دانلود می‌شود.

نسخه‌ها: AGP 8.7.3، Gradle 8.9، compileSdk 35 (target 34، min 24)، Media3 1.5.1. شناسهٔ برنامه `com.sovio.app` است.

## نکات

- بار اول که فایلی را باز می‌کنی، ویوفرم در پس‌زمینه ساخته می‌شود (فایل ۲ ساعته حدود چند ده ثانیه)؛ در همین مدت پخش و اسلایدر عادی کار می‌کنند. نتیجه ذخیره می‌شود و دفعهٔ بعد فوری است.
- «خودکار» در تقویت صدا بعد از پایان تحلیل ویوفرم کار می‌کند.
- **اعلان‌ها باید روشن باشند** تا صفحهٔ قفل کنترل نشان بدهد (اندروید ۱۳ به بعد موقع اولین اجرا می‌پرسد). اگر خاموش باشد، برنامه یک بار پیشنهاد می‌دهد تنظیماتش را باز کنی.
- اگر در گوشی‌های سامسونگ باز هم بعد از مدتی پخش قطع شد: تنظیمات ▸ برنامه‌ها ▸ Sovio ▸ باتری ▸ «بدون محدودیت».
- اگر روی دستگاهی مسیر لیمیتر در دسترس نباشد، برنامه خودکار از `LoudnessEnhancer` اندروید استفاده می‌کند.
- تست واحد DSP لیمیتر (روی JVM):
  ```
  javac -d out app/src/main/java/com/meowsic/app/GainLimiter.java tools/GainLimiterTest.java
  java -cp out com.meowsic.app.GainLimiterTest
  ```

## ساختار

`app/src/main/java/com/meowsic/app/` (نام پوشهٔ سورس قدیمی مانده تا آپدیت مخزن ساده باشد): `PlaybackService` (موتور پخش، نوتیفیکیشن، صفحهٔ قفل)، `QueueStore` (آخرین فایل)، `GainLimiter` + `BoostProcessor` (تقویت صدا)، `WaveformView` / `WaveformExtractor` / `WaveformStore` / `WaveformData` (ویوفرم)، `PlayerActivity`، `MainActivity`، `SpeedSheet` (سرعت/پیچ/بوست/ثانیهٔ عقب و جلو)، `SkipDialog`، `Library` (فایل‌های گوشی).

## مجوز و منبع

تنظیمات موتور پخش (ExoPlayer، جستجوی دقیق، استخراج‌کنندهٔ MP3 و …) از روی [AntennaPod](https://github.com/AntennaPod/AntennaPod) (GPL-3.0) الگو گرفته شده؛ اگر برنامه را منتشر می‌کنی، مجوز GPL-3.0 را رعایت کن.
